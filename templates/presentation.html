System Architecture

Zero-Build, Full-Stack Design

Three-tier decoupled architecture: instant load times, zero npm vulnerabilities, ACID reliability.

🖥️
Frontend — Vanilla SPA
Pure HTML5 + ES6 JavaScript. No React, no webpack, no npm. Sub-50ms initial render with glassmorphic dark-mode design tokens.
HTML5 ES6 CSS3 Zero Build
⚙️
Backend — Python Flask REST API
RESTful endpoints for CRUD + AI triage & copilot chat. Dual routing (/records & /api/records), CORS, input validation, role-based audit headers.
Python 3 Flask REST JSON CORS
🗄️
Database — SQLite3 ACID Engine
Embedded single-file database. Full ACID transactions, foreign-key audit trail, auto-seeding on first boot. Zero infrastructure overhead.
SQLite3 ACID Foreign Keys Auto-Seed

Data Model & Schema

Engineered for Customer & Product Context

Structured entities combining operational ticketing, customer financial exposure, and automated AI metadata.

📋
records — Primary Support Entity
14 Columns
id INTEGER PRIMARY KEY AUTOINCREMENT ticket_key TEXT UNIQUE (e.g. 'TICK-101') title TEXT NOT NULL description TEXT NOT NULL customer_name TEXT NOT NULL customer_tier TEXT Enterprise | Mid-Market | Growth category TEXT Bug | Escalation | Feature Req priority TEXT P0-Blocker → P3-Low status TEXT Open → In Progress → Resolved assigned_eng TEXT Technical lead impact_revenue REAL $ ARR at risk ai_sentiment TEXT Frustrated | Negative | Neutral ai_summary TEXT AI executive digest ai_action TEXT Recommended roadmap action
📜
activity_logs — Immutable Audit
Append-Only
record_id FK → records.id action CREATED | UPDATED | STATUS_CHANGE details Field mutation diff actor 'Alex Rivera (Staff SE)' timestamp ISO-8601 UTC

Why This Design Matters
  • impact_revenue ties technical bugs directly to customer ARR — product managers see dollar impact, not just ticket counts
  • activity_logs provides full traceability: who changed priorities, assigned leads, or resolved tickets — and when
  • ai_sentiment + ai_summary enable automated executive escalation before customer churn

Technical Reflection & Close

Technical Thinking, AI Tools & Extensibility

Pragmatic trade-offs, AI-accelerated development, and a clear path to production.

🧠
Technical Decisions
  • Zero-Build Philosophy: Vanilla JS over React/Next.js — zero build steps, zero npm CVEs, instant demo reliability
  • ACID First: SQLite ensures transactional integrity in a portable single-file deployment
  • Dual API Routes: Both /records and /api/records for universal client compatibility
⚡
AI Tools Leveraged
  • Schema Generation: AI drafted relational SQLite schema + FK constraints in minutes
  • Realistic Seed Data: Generated authentic enterprise ARR, stack traces, and HTTP error codes
